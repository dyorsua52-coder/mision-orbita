# Misión Órbita

## Descripción del proyecto

Misión Órbita es un simulador básico de preparación de misiones de exploración espacial desarrollado en Python para el curso Principios de Programación 1.

El primer avance contiene cuatro programas independientes que calculan los recursos necesarios, verifican el combustible, comprueban el soporte de la tripulación y determinan si se autoriza el lanzamiento.

## Estructura del proyecto

* `avance1/`: programas de Python correspondientes al primer avance.
* `diagramas/`: diagramas de flujo de los cuatro ejercicios.
* `pruebas/`: documentación y evidencias de los casos de prueba.
* `documentacion/`: documento PDF de la entrega.

## Programas

1. `ejercicio1_recursos.py`: cálculo de recursos necesarios para una misión.
2. `ejercicio2_combustible.py`: verificación del combustible disponible.
3. `ejercicio3_soporte_tripulacion.py`: verificación de oxígeno y provisiones.
4. `ejercicio4_autorizacion.py`: autorización inicial de lanzamiento.

## Instrucciones de ejecución

1. Abrir la carpeta del proyecto en Visual Studio Code.

2. Abrir una terminal desde **Terminal → New Terminal**.

3. Ejecutar el programa deseado con Python. Por ejemplo:

   `python avance1/ejercicio1_recursos.py`

4. Introducir los datos solicitados por la consola.

## Convenciones y restricciones

* Utilizar nombres descriptivos de variables en `snake_case`.
* Declarar las constantes al inicio de cada archivo con nombres en mayúsculas.
* Mantener una indentación de cuatro espacios.
* Incluir encabezados y comentarios que documenten los bloques lógicos.
* No utilizar ciclos, colecciones, funciones propias, librerías externas ni condicionales `elif` o anidadas.
* Utilizar únicamente entradas y salidas por consola.
* Mantener cada ejercicio en un archivo `.py` independiente.
